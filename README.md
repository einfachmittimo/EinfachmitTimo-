# EinfachmitTimo – Rezeptdetails

Beim Klick auf „Zutaten & Zubereitung ansehen“ wird das Rezept rechts neben der Übersicht (auf schmalen Displays darunter) mit skalierbaren Zutatenmengen, Zubereitungsschritten und verfügbaren Nährwerten angezeigt.

## Aktualisieren
1. Lade `app.py` und `recipes.json` in dein GitHub-Repository hoch und ersetze beide Dateien.
2. Logo und Porträt bleiben erhalten; falls du diese Dateien bereits im Repository hast, musst du sie nicht erneut hochladen.
3. Committe die Änderungen und warte auf den Streamlit-Neustart.

Die Datei `recipes.json` enthält die vorhandenen Rezepte mit ergänzten Zubereitungsschritten.
